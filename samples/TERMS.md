# Ketentuan Katalog Demo GENJUR STREAM

Katalog ini adalah data demonstrasi buatan untuk menguji fitur repositori dan ekstensi GENJUR STREAM.

- Judul, sinopsis, dan metadata di dalam katalog merupakan contoh fiktif.
- Katalog ini tidak menyediakan atau mengklaim memiliki hak atas film pihak ketiga.
- Tidak ada tautan video untuk diputar.
- Data boleh digunakan untuk pengujian tampilan aplikasi.
